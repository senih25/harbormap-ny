# Community code of conduct

HarborMap NY exists to improve access to everyday public services, not to debate political positions, question anyone's immigration status, or collect sensitive personal information.

**Expected:** Be respectful, factual, accessible, considerate across languages and backgrounds, and clear about evidence, geography and uncertainty. Correct errors constructively. Keep issues about the project and verified public information.

**Not accepted:** harassment, discrimination, threats, identity targeting, doxxing, immigration-status speculation, posting private addresses or documents, unsolicited promotion, disinformation about public programs, or instructions to bypass safeguards.

Moderators may edit, hide, lock or close conversations and restrict participation when needed to protect people and the project. Publishing an issue or PR does not give permission to modify or deploy HarborMap NY.

Report security vulnerabilities through the repository's **private vulnerability reporting** feature. For other conduct concerns, use GitHub's reporting/moderation controls without sharing private details publicly.

The maintainer will act within available capacity; this volunteer project makes no guaranteed response or support service commitment.
