# Contributing to HarborMap NY

HarborMap NY is a civic-benefit project focused on safe, practical access to verified New York City public services. Thoughtful corrections and accessibility reports are useful; maintenance and publication decisions remain with the repository owner.

## Best ways to help

1. **Report a public-data error** using the data-correction issue template, with the original agency URL and dataset identifier.
2. **Report an accessibility or usability issue** without including identifiable user information or precise private locations.
3. **Suggest features** that improve safety, multilingual clarity or lawful public-data coverage.

**Before writing substantial code, open an issue.** Unsolicited pull requests may be closed without merging. Review discussion does not grant repository write access. Contributions are screened for security, data provenance, licensing, privacy, scope and actual maintainability.

## A pull request must

- Be narrow, sourced and relevant to NYC public-service discovery.
- Link its issue and explain the observable user benefit.
- Avoid accounts, tracking, invasive geolocation, status profiling, hidden shelters and real-time claims without verified feeds.
- Include the exact source agency, URL, attribution/terms, update timestamp and geographic coverage for any added dataset.
- Run `npm test` and state what was **not** tested. Screenshots must not reveal personal data.
- Avoid external runtime dependencies or privileged operations without advance issue discussion.
- Respect [CODEOWNERS](.github/CODEOWNERS); only the authorized maintainer can choose to merge.

**No automated merging and no implicit permission to publish.** A public fork or pull request cannot change the protected deployed branch without the repo's authorization and checks.

## Licensing boundaries

This repository currently has **no explicit blanket open-source software license**. Public visibility does not automatically permit redistribution or relicensing of code, branding or included datasets. Third-party publishers retain applicable data terms. Discuss reuse rights before proposing a license or moving large datasets.

## Language quality

Translation contributions must preserve service disclaimers and be checked with native/professional readers when possible, especially for legal-adjacent, health and crisis-support wording. No invented benefit eligibility or hours.

## Safety

Do not post personal details, immigration records, home addresses or private shelter locations. For vulnerabilities, use [private GitHub reporting](https://github.com/senih25/harbormap-ny/security/advisories/new), not an issue.

For actual emergencies, seek the appropriate real-world service; this repository is not a help desk or emergency dispatcher.
